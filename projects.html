FM Bandpass Filter
88–108 MHz — UCCS Workshop Build

Design and construction of a bandpass filter for a 500mW FM transmitter. RTL-SDR analysis identified 2nd and 4th harmonics — consistent with a sawtooth oscillator clock. Filter built at UCCS workshop. Prerequisite for the CSST Part 15 school radio station.

NanoVNA Antenna Measurements
NanoVNA V2 — SWR, Impedance, S21

NanoVNA-based measurement campaign validating FR-2026-05 predictions. Antenna SWR and impedance measurements across frequency. S21 isolation between the two installed antennas to compare against the free-space co-polarized isolation model. A measured vs. predicted S21 comparison is publishable in its own right.

Hydrogen Line Receiver
1420.405 MHz — 21cm

First radio astronomy project. RTL-SDR V3 with a dedicated feedhorn and 1420 MHz LNA. Building on existing station hardware. Target: confirmed hydrogen line detection and galactic structure mapping via Doppler shift analysis.

◆ Complete
Stellar Labs 30-2460 Pattern Model
MATLAB R2025b — 7.375 dBi Simulated

The Stellar Labs 30-2460 4-element FM Yagi doesn't include a radiation pattern in its documentation. Modeled independently in MATLAB using the array factor derivation and pattern multiplication theorem. Simulated gain: 7.375 dBi. First independently derived antenna pattern model for FRRRI.
