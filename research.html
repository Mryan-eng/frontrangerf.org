FRRRI-STATION-001
Dual-Band ADS-B Permanent Receive Station
978 / 1090 MHz — South of Fountain, CO
Active

Two-antenna permanent ADS-B receive station on a metal garage roof. Primary mission: long-term coverage data collection to study terrain-influenced VHF/UHF propagation asymmetry caused by the Front Range mountains. Flat open prairie to the east provides near-textbook free-space propagation. The Front Range and Pikes Peak to the west create a hard terrain horizon at roughly 2–3° elevation — the natural asymmetry is what makes the site scientifically valuable. Research question: how accurately does the Irregular Terrain Model predict where the deviation occurs?

Hardware

  • FlightAware dual-band collinear, 978/1090 MHz, 6 dBi
  • Tram Model 1411 discone, 25–1300 MHz
  • SAWbird+ LNA, Raspberry Pi 4 8GB
  • RTL-SDR V3, dump1090-fa, PiAware

Software Stack

  • dump1090-fa → ADS-B decode, port 8080
  • OpenWebRX → general SDR, port 8073
  • Tailscale → remote access
  • Daily JSON archive → /data/adsb/

FR-2026-05
Co-siting Analysis of a Dual-Band ADS-B Receive Station
Maxwell → Helmholtz → Far-Field Integral → E(φ) pattern formula
Draft

Full analytical co-siting study for the dual-band ADS-B station. Elevation radiation patterns derived from Maxwell's equations via the far-field monopole integral, extended to the collinear case using the pattern multiplication theorem and array factor. The FlightAware collinear's internal construction was reverse-engineered from the published 28° HPBW specification, yielding N=4 half-wave elements and 6.4 dBi modeled gain — consistent with the spec. Co-polarized isolation modeled as a function of separation distance and frequency. FM broadcast band identified as the binding isolation constraint, requiring 2.3–2.5m for 20 dB. Placement recommendation provided. All MATLAB code available at frontrangerf.org.

Derivation Chain

  • Maxwell's equations in free space
  • Wave equation → Helmholtz equation
  • Boundary conditions → standing-wave current I(z)
  • Far-field integral → E(φ) pattern formula
  • Array factor + pattern multiplication theorem

Key Findings

  • FlightAware collinear = N=4 half-wave elements
  • FM band is binding isolation constraint
  • 2.3–2.5m separation for 20 dB at FM
  • Metal roof exceeds λ/4 at all frequencies 50–1090 MHz
  • Incidental quasi-NVIS from pitched roof geometry

THE 88-MILE CHALLENGE
VHF Propagation Across the Rampart Range
99.5 MHz (KQMT-FM) — Lookout Mountain → Pikes Peak Int'l Raceway — 88.33 miles
Complete

Inaugural FRRRI field study. Characterized VHF signal persistence across an 88.33-mile obstructed path with the Rampart Range (7,000–9,000 ft elevation) as the primary terrain obstacle. A continuous 99.5 MHz transmission was used as a stable reference source to evaluate real-world attenuation relative to theoretical free-space path loss and line-of-sight assumptions. The analysis considered geometric path obstruction, diffraction effects over mountainous terrain, and summed theoretical path loss exceeding 110 dB. Field observations demonstrated that directional antenna gain and receiver system optimization materially influenced signal recoverability. Results suggest practical link performance can exceed simplified LOS expectations when system-level parameters are carefully engineered. Qualitative study — provided the exploratory framework for FRRRI's quantitative work. Reviewed by Dr. Paul Wilkinson, SIEEE, in association with the Pikes Peak Radio Amateur Association.

Equipment

  • Stellar Labs 30-2460 4-element FM Yagi, +6 dBi
  • RTL-SDR V4 as RF spectrum receiver
  • RTL LNA in series with feedline
  • 5V DC via built-in bias tee
  • GQRX SDR software, low-loss RG-6 coax

Methodology

  • Midday observations — constant time variable
  • Clear day conditions — normal atmospheric/solar
  • GIS terrain analysis for path geometry
  • Free-space path loss as theoretical baseline
  • Qualitative signal recoverability assessment
